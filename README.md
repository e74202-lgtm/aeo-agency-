# Samael website

Marketing site for an AEO (Answer Engine Optimization) agency. See [PLAN.md](PLAN.md) for the full plan.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Stack
Next.js (App Router) + TypeScript, Tailwind CSS, shadcn/ui. Site name, nav and CTA live in `src/lib/site.ts`.
